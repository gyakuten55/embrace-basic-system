# エンブレース 介護業務システム

訪問介護・障害福祉サービス事業所のための基幹業務システムです。
**契約 / 会議記録・担当者会議 / 介護計画書 / スケジュール・記録・実績 / 勤怠管理** を
ひとつのシステムで扱えるようにしたものです。

現場の記録入力は音声とAI整形で短縮できます。


## できること

| 機能 | 内容 |
| --- | --- |
| ダッシュボード | 当日の訪問、記録の未入力、認定期限・計画期間切れなどの要対応事項 |
| スケジュール | 週間グリッド（職員別／利用者別）、予定の追加・編集、**計画書から1か月分を一括作成** |
| サービス記録 | **音声入力＋AI整形**。バイタル・実施項目・特記事項を自動で振り分け |
| 実績・集計 | 月次の提供実績、利用者別の実績記録票（印刷可）、CSV書き出し |
| 利用者 | 基本情報、保険・認定、緊急連絡先、既往歴。契約・計画・記録を1画面で確認 |
| 契約 | 契約書・重要事項説明書・個人情報同意の取得状況を一覧で管理 |
| 介護計画書 | 意向・方針・長短期目標・週間サービス内容。印刷可。次の版として複製できる |
| 会議記録 | サービス担当者会議・事業所内会議・研修の記録と出席者。印刷可 |
| 勤怠管理 | 月次グリッド、職員ごとの1か月一括入力、打刻、実働時間集計、CSV書き出し |


## 記録のAI整形について

ヘルパーが話した内容を、そのまま記録として残せる文章に整えます。

```
話した内容:
  えーと体温36度8分、血圧は132の80です。服役の確認をしてから、
  お風呂は微熱があるんで見送って正式で対応しました。麦茶を200ml飲まれてます。

整形結果:
  体温 36.8℃ / 血圧 132-80 / 水分 200ml
  入浴: 中止   実施項目: 服薬介助・清拭／部分浴・バイタル測定・水分補給
  用語の補正: 服役 → 服薬 ／ 正式 → 清拭
```

- **音声入力**は Web Speech API を使います（Chrome / Edge / Android Chrome / iOS Safari）。
  対応していない環境でも、文字入力とAI整形は使えます。
- **整形エンジンは2系統**あります。
  - `ANTHROPIC_API_KEY` を設定 → Claude API で整形（文章がより自然になります）
  - 未設定 → 内蔵エンジンで整形（APIキー不要。オフラインでも動作）

  API が落ちても内蔵エンジンの結果を返すため、**記録入力が止まることはありません。**
- 音声認識の誤変換は `src/lib/care-terms.ts` の辞書で補正します。
  現場で出た誤変換はここに追記して育てていく想定です。


## 動かし方

```bash
npm install
npm run dev          # http://localhost:3000
```

初回起動時にデータベース（`data/embrace.db`）と初期データが自動で作られます。

| --- | --- | --- |

| 1002 | 中村 由美 | サービス提供責任者 |
| 2001 | 大野 千代 | 介護職員 |

パスワードはいずれも `embrace` です。**運用開始前に設定画面から変更してください。**

### 本番運用

```bash
npm run build
npm start
```

`.env.example` を `.env` にコピーして設定します。

| 環境変数 | 用途 |
| --- | --- |
| `SESSION_SECRET` | セッションCookieの署名キー。**本番では必ず独自の値に変更** |
| `ANTHROPIC_API_KEY` | 記録整形に Claude API を使う場合のみ |
| `DATABASE_FILE` | SQLite ファイルの配置先（既定 `./data/embrace.db`） |

### そのほかのコマンド

```bash
npm run typecheck    # 型チェック
npm run db:reset     # データベースを削除して初期データから作り直す
```

### 動作確認（E2Eテスト）

ログインから記録入力・実績・勤怠・削除まで、主要な業務の流れを実際のブラウザで確認します。

```bash
npm i -D playwright && npx playwright install chromium
npm run dev                       # 別のターミナルで
npm run e2e                       # 35項目をチェックし、画面の写真を e2e-screenshots/ に保存
```

テスト中にデータが書き込まれるため、本番のデータベースには向けないでください。
確認用のデータベースを使うときは `DATABASE_FILE=./data/test.db npm run dev` のように起動します。


## 構成

```
src/
  app/
    (app)/           ログイン後の画面（サイドバー付き）
    actions/         Server Actions（登録・更新・削除）
    api/             AI整形 / CSV書き出し
    login/           ログイン
  components/        共通UI、音声入力フック、ナビゲーション
  lib/
    db.ts            スキーマ定義とマイグレーション
    seed.ts          初期データ
    ai.ts            記録のAI整形（Claude API ＋ 内蔵エンジン）
    care-terms.ts    介護用語の誤変換辞書、実施項目の定義
    queries.ts       一覧・詳細の取得
    attendance.ts    実働時間の計算
    date.ts          日付・時刻のユーティリティ
```

- **Next.js 15（App Router）/ TypeScript / Tailwind CSS / SQLite（better-sqlite3）**
- データベースは1ファイルなので、バックアップは `data/embrace.db` のコピーで足ります。
